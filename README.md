# Random Number Generator 1–49

A mobile-friendly random number generator.

## Features
- Generates unique numbers from 1–49
- Choose 2–12 numbers per draw
- Exclude any numbers you do not want drawn
- Remembers exclusions on the device
- Keeps the 10 most recent draws
- No server or database required

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide your public Pages address.
